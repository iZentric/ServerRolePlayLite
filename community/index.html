04 / EXPLORARE
Comunitatea înaintea pluginurilor

Un server Paper-only.
O comunitate reală.

FunCity rulează Paper cu pluginuri Bukkit/Paper și client Java nemodat; fără Forge, moduri de client sau motor hibrid. Compatibilitatea se verifică pentru versiunea Minecraft și versiunile exacte ale pluginurilor înainte de publicarea unui release.

Urmărește anunțul oficial

Verifică data deschiderii, versiunea Minecraft, launcherul acceptat și pluginurile server-side anunțate.

Nu descărca arhive trimise în mesaje private.

Pornește versiunea Java corectă

Folosește clientul Java compatibil cu versiunea serverului; nu este necesar un modpack de client.
