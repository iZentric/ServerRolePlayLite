# FunCity RP Lite — selecție de moduri client (nu pack instalat)

**20.10.2026:** din cele [28 de nume declarate pentru Freeroam 1.0.0](FREEROAM-LISTA-DECLARATA.json), [selecția țintă](FUNCITY-RP-LITE-SELECTIE.json) exclude **patru**: `CTM-MC1.16.1-1.1.2.6.jar`, `DynamicSurroundings-1.16.5-4.0.5.0.jar`, `InGameAccountSwitcher-Forge-1.16-8.0.1.jar` și `lightfallclient-1.0.0.jar`. Celelalte 24 rămân în ținta declarată, inclusiv vocea, modurile RP și optimizatoarele deja prezente. Este doar o selecție în repository: **niciun fișier JAR, profil Prism, Freeroam original sau server nu a fost schimbat**. LowSpec-ul de 21 este experimentul FunCity istoric, nu acest pack.

**A cincea scoatere cerută este blocată:** `TRansliterationLib-1.0.4.jar` este dependență obligatorie pentru `notenoughanimations-1.2.4.jar`, pe care proprietarul a ales explicit să îl păstreze. [Pagina dependențelor pentru exact 1.2.4](https://www.curseforge.com/minecraft/mc-mods/not-enough-animations/files/3296039/dependencies) marchează biblioteca drept Required Dependency. Nu forțăm o țintă de 23 JAR-uri cu dependență lipsă; cerem o alegere separată despre pereche. Nu schimbăm versiunea modului păstrat fără aprobare și teste.

**Încă nu știm dacă selecția de 24 funcționează.** Scoaterea CTM poate modifica texturi/resource-packuri, iar fără Lightfall Client conectarea la un server care cere handshake-ul Lightfall poate eșua; infrastructura de conectare și resursele reale nu au fost auditate. Lista de 28 este furnizată în conversație, **nu inventar/SHA de pe PC**; dacă originalul conține și alte JAR-uri, oprim și investigăm, nu le ștergem. [Jobul PC](https://github.com/iZentric/ServerRolePlayLite/actions/runs/39439372232) nu a furnizat inventarul Freeroam.

[Validatorul read-only](../scripts/fc_original_plus_optimizers.py) compară o copie candidată cu inventarul original: acceptă **numai** aceste patru excluderi, cere SHA identic pentru orice JAR reținut și refuză adăugiri, scoateri suplimentare ori un original diferit de lista declarată. Trece doar poarta pentru **teste de compatibilitate**, nu dovedește boot, login sau release. [Răspunsurile proprietarului](FREEROAM-RASPUNSURI-28.json) rămân sursa deciziilor.

Rubidium, FerriteCore și ModernFix sunt deja în listă; LazyDFU rămâne preferat, TexTrue rămâne cu Rubidium. Entity Culling și Embeddium se discută ulterior, fără instalare ori înlocuire acum. Niciun Dynamic FPS. Setări pentru viitoare teste pe PC slab: 5 chunkuri, Fast, shaders oprite, particule minime, mipmap 0, umbre entități oprite. Efectul asupra FPS în joc activ este **nemăsurat**.

Înainte de un ZIP/release: inventar/SHA reale, auditul celorlalte dependențe și licențe, verificare resurse CTM/handshake Lightfall, test client Forge + server izolat cu voce/login, backup/restore și FPS măsurat. Fără acces la aceste probe nu promitem un pack funcțional pe orice PC.
