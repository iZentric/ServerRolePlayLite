# Testul cerut: RoadRunner vs Performant pe GitHub, fără PC sau live

22.10.2026. [Runda GitHub Actions **39690162286**](https://github.com/iZentric/ServerRolePlayLite/actions/runs/39690162286) a reușit pe un **runner GitHub Ubuntu izolat**. Scriptul [fc_server_optimizer_ab.py](../scripts/fc_server_optimizer_ab.py) și [workflowul](../.github/workflows/server-optimizer-ab.yml) au testat același motor FunCity b1.0827/Java 11, **15 JAR-uri RP istorice (11 conținut + 4 dependențe)**, aceleași 6 pluginuri și același FerriteCore/ModernFix. A fost descărcat **fișierul oficial Performant 4.1m, CurseForge file ID 4562378**, SHA256 `7451c817430b509eb88dcd23933973110ed659a06f3cfdb1933ceb33bdfab656`, verificat ca mod Forge `performant`. Nu s-a publicat/reîmpachetat binarul.

**Ce s-a schimbat între brațe:** R = `RoadRunner-mc1.16.5-1.5.2.jar`, P = RoadRunner **scos**, `performant-1.16.2-5-4.1m.jar` **pus în loc**. Nimic altceva intenționat. Am creat o lume nouă **sintetică** pe runner, apoi am copiat-o identic la fiecare probă; serverul s-a legat la loopback, cu online-mode și whitelist active. Fiecare probă a pornit independent, a activat cele 6 pluginuri, a confirmat 80 de zombie prin consolă, a rulat ~30 s, apoi s-a oprit curat. Ordine **R/P/P/R**; toate cele patru probe au trecut. Nu există lume/jucători reali, cliente grafice, acces public, upload de loguri/JAR-uri, scrieri pe PC sau live.

| Indicator pe runner, două probe/braț | R = RoadRunner | P = Performant | Interpretare |
|---|---:|---:|---|
| **Mean tick time** mediană din raportările `forge tps` per probă (ms) | **3,22; 2,71** | **1,57; 2,26** | **Performant este mai mic în AMBELE probe sintetice**. Diferența medianelor celor două brațe: ~1,05 ms (R ~2,97 vs P ~1,92). Nu este MSPT p95/p99 și nu reprezintă TPS la jucători reali. |
| CPU Java / fereastră ~30 s (secunde CPU) | **6,00; 5,85** | **7,47; 7,52** | RoadRunner a consumat **mai puțin CPU** în ambele probe (P poate folosi paralelism; timpul CPU nu este timpul unui tick). |
| RSS Java mediană în fereastră (MiB) | **2693,31; 2381,36** | **2404,40; 2529,69** | Semnal mixt; nu declarăm câștigător RAM. |

**Răspuns direct pentru server:** dacă prin „mai bun” înțelegem **timpul mediu de tick pe această scenă GitHub** cu 80 mobi, **Performant a câștigat**. Dacă înțelegem **consum CPU**, **RoadRunner a câștigat**. Pentru **FunCity RP real cu NPC/vehicule**, nu este încă demonstrat că Performant e cel mai bun sau că păstrează comportamentul; scenele, pluginurile live și lumea reală diferă, n-am testat login/voice/vehicule, iar probele sunt scurte (2/braț, fără jucători). Nu confundăm câștigul de ~1 ms pe runner cu FPS client sau capacitate pentru zeci de jucători.

**Alegerea pe care o fac acum:** păstrez **RoadRunner pe serverul existent**, nu din cauza unui „benchmark câștigat”, ci pentru că rulează deja în inventarul istoric și avem nevoie să păstrăm mecanicile RP; **Performant este candidatul prioritar de TEST pe copie privată**, pentru că noua măsurătoare arată un posibil beneficiu server-side. Dacă trece testele NPC/vehicule/spawn și un A/B MSPT p95/p99 sub sarcină reală pe **copie**, îl alegem în loc de RoadRunner, niciodată împreună. La client, profilul Lite **Rubidium + Oculus 22 JAR-uri** rămâne alegerea funcțională; GitHub Actions nu poate măsura FPS-ul plăcii video a proprietarului.
