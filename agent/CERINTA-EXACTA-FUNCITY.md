# Cerința exactă FunCity pentru un agent de cod (copiezi mesajul de mai jos)

> Lucrează în `iZentric/ServerRolePlayLite`, pe branch-ul deja alocat sesiunii. Citește mai întâi `AGENTS.md`, `agent/SELECTIE-MOTOR-MODURI-CLIENT.md`, `agent/DECIZII.md`, `agent/PROGRES.md` și inventarul PC disponibil. Nu îmi cere din nou versiunea de Minecraft, lista de moduri sau să schimb proiectul în Paper: **Minecraft 1.16.5, Forge + pluginuri, FunCity RP Lite** sunt decizii ale proprietarului. HYPECITY este reperul meu real de comunitate, nu dovada că noul server a fost testat la același număr de jucători. Dacă o dovadă nouă contrazice o decizie, spune de ce înainte de a o schimba.
>
> **Rezultatul cerut:** un server hibrid FunCity pe care să pot intra cu un client Lite, cu RP funcțional, și o evaluare cinstită a capacității pe gazda testată. Vreau aspect/mesaje FunCity, compatibilitate mod–plugin, nu să fie eliminat Forge doar ca să sune „optimizat”. Nu inventa un motor de la zero: folosește baza FunCity b1.0827 aleasă și schimbă codul doar pentru erori/hotspoturi demonstrate.
>
> **Fă, în această ordine, ce este executabil:**
>
> 1. Inventariază read-only motorul/JAR-ul și SHA-ul lui, configurația încărcată, modurile/pluginurile și clientul de test; separă clar PC, server de test, istoric HYPECITY și live. Nu tipări secrete, conturi ori date de jucători. Dacă GitHub logs sau un transport nu merg, încearcă o singură alternativă și continuă cu partea independentă de ele.
> 2. Construiește un **stage separat**, fără a atinge lumea live. Motor țintă: FunCity b1.0827. Folosește selecția existentă **29 moduri server / 24 moduri client**, nu reconstrui pe nevăzute CUANTIC ori HYPECITY. Verifică SHA, licențe, dependențe și identificatorii Forge; `scripts/fc_server_lite_candidate.py` și `scripts/fc_lite_repack.py` produc doar candidați structurali, nu instalare. Vocea trebuie pe ambele părți. Nu scoate mobilier, vehicule sau arme fără test.
> 3. Pentru server, pornește din configurațiile `functity-config/` numai după verificarea cheilor suportate pe motorul **1.16.5**: view 5, spawn 20/6/2, compresie 256, `nerf-spawner-mobs=false`, item despawn 6000, keep-spawn și Ksyxis până la A/B. Nu inventa `simulation-distance` Paper modern și nu reduce orb vizibilitatea RP. Schimbă o variabilă pe rând, măsoară MSPT/TPS/CPU/RSS/GC/disc/rețea și revino la bază dacă strică jocul. `max-players` nu este număr de jucători susținuți.
> 4. Pentru client, fă importul `.mrpack` pe profil **nou**, pe un PC disponibil prin runner; nu suprascrie Prism-ul existent. Verifică toate descărcările, conectarea tehnică Forge, obiectele/vehiculele/modurile comune și vocea între doi clienți. Autentificarea contului e **prin plugin**, nu „login Forge”: pluginul concret, JAR-ul și configurația trebuie identificate/verificate înainte să pretinzi că merge. Testează FPS p5/median, RAM și timp de instalare pe hardware modest; **nu promite orice laptop OLX** fără o probă pe configurația lui.
> 5. Orașul nou este construit liber de jucători, **fără claims sau protecții preventive**. CoreProtect este doar jurnal și rollback manual admin; verifică acțiuni pe blocuri modate și restaurarea unei copii. Backupul verificat și restaurat este condiție înainte de modificarea serverului live. Nu copia date de cont, UUID-uri, parole, lumi istorice ori configurații de securitate din HYPECITY.
>
> **Livrabile:** commiturile pe branch-ul sesiunii, configuri de stage, scripturi care refuză SHA/inventar greșit, client și server verificate împreună, rezultate de teste legate de commit, plus un README scurt „cum intru” numai dacă importul și intrarea au reușit. Dacă nu ai acces la motor/runner/hosting sau testele eșuează, nu spune „gata”: oferă rezultatul parțial concret, proba erorii și următorul pas executabil, fără să-mi ceri să repar manual PC-ul. Raportul final: **ALES / APLICAT / VALIDAT / LIVE**; o capacitate de jucători numai după măsurătoare reprezentativă.

## De ce nu folosim promptul „Paper only” din conversația externă

Paper elimină Forge și modurile reale de mobilier/vehicule/arme/voce pe care le-ai cerut; resource packul nu înlocuiește automat gameplay-ul și registrul de iteme. Recomandări pentru Paper modern (`paper-world-defaults.yml`, `simulation-distance=4`, Java pentru 26.x, un JAR Paper descărcat) nu se transferă direct pe motorul hibrid 1.16.5. Nici hibridul ales nu garantează FPS pe orice laptop sau un anumit număr de jucători; acestea se verifică separat. Cererea de „motor propriu” se traduce în patchuri mici, licențiate și comparate cu b1.0827, nu într-un proiect nou inventat și netestat.
