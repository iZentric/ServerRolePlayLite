# FunCity — planul de pornire a comunității

Acest document este planul de lucru pentru comunitate, nu dovadă că un canal Discord, server public sau echipă de moderare există deja. Publicăm linkurile și datele de conectare numai după ce proprietarul le confirmă.

Pagina de prezentare: [`community/index.html`](../community/index.html).

## Identitatea comunității

- **Nume oficial:** FunCity
- **Tratament vizual:** FUNCITY
- **Identificatori tehnici:** `funcity`, numai unde nu rupe compatibilitatea
- **Direcție:** Roleplay urban cu viață civilă, afaceri, facțiuni/mafii și survival opțional
- **Arhitectură curentă:** server Paper-only cu pluginuri Bukkit/Paper; client Minecraft Java nemodat. Modurile/Forge și motoarele hibride nu fac parte din acest rollout.
- **Principiu:** gameplay-ul și oamenii au prioritate față de numărul de moduri, pluginuri sau scorurile de benchmark

Păstrează numele CUANTIC în documentele și release-urile istorice unde este necesar pentru proveniență. Nu schimba automat ID-uri de mod/plugin, package-uri Java, nume de lumi, baze de date, permisiuni sau căi persistente.

## Structura propusă pentru Discord

Creează canalele numai după ce proprietarul a creat/confirmat serverul Discord și a desemnat moderatori.

### START AICI

- `#bun-venit` — scopul comunității și pașii de acces
- `#anunturi` — doar anunțuri ale echipei; fără ping-uri în masă implicite
- `#reguli` — reguli scurte, versiune și data ultimei actualizări
- `#alege-rolurile` — notificări opționale: anunțuri, testare, facțiuni, suport

### COMUNITATE

- `#discutii`
- `#povesti-din-oras` — numai povești in-character; etichetare clară
- `#idei-si-voturi` — sugestii cu stare: nouă / analizată / acceptată / refuzată
- `#media` — capturi și clipuri, cu acordul persoanelor vizibile

### SUPORT

- `#ajutor-instalare` — launcher, Java, memorie, erori de conectare
- `#raporteaza-o-problema` — formular/template; fără parole, tokenuri, IP-uri private sau dump-uri brute
- `#status-si-mentenanta` — incidente și ferestre de mentenanță, cu ore și actualizări

### STAFF — privat, acces minim necesar

- `#mod-log` — acțiuni de moderare, fără publicarea datelor sensibile
- `#staff-coordonare`
- `#escaladari` — contestații și cazuri care necesită mai mult de un moderator

Nu crea canale vocale persistente obligatorii și nu cere membrilor să-și dezvăluie numele real, vârsta exactă, adresa sau date de cont.

## Reguli de bază — proiect de revizuit înainte de publicare

1. Respectă jucătorii; conflictul RP rămâne între personaje.
2. Fără hărțuire, doxxing, amenințări, discriminare sau urmărire în afara jocului.
3. Fără metagaming, powergaming, exploit-uri, cheat-uri sau abuz de buguri.
4. Acțiunile cu miză mare cer interacțiune și posibilitate rezonabilă de răspuns; nu forța rezultate asupra altui personaj.
5. Raidurile, furtul, PvP-ul și conflictele dintre facțiuni urmează regulile RP publicate; nu presupune că orice este permis.
6. Protejează lumea și construcțiile. Raportează griefing-ul; nu răspunde prin răzbunare.
7. Respectă staff-ul, dar orice sancțiune poate fi contestată prin canalul/procesul oficial.
8. Nu posta loguri brute, IP-uri, credențiale sau date personale. Redactează dovezile înainte de a le trimite.

## Rollout în pași mici

### Gate A — înainte de invitații

- [ ] Proprietarul confirmă Discordul oficial și accesul de administrare.
- [ ] Minimum doi moderatori desemnați și proces de apel.
- [ ] Reguli RP, protecția lumii, economie și PvP aprobate de proprietar.
- [ ] Linkuri, roluri și canale verificate; permisiuni staff cu acces minim.
- [ ] Nicio adresă IP sau invitație neconfirmată pe pagina publică.

### Gate B — înainte de testul închis

- [ ] Release server/client fixat prin versiune și SHA-256.
- [ ] Clientul Minecraft Java nemodat se conectează la buildul Paper exact.
- [ ] Salvare, oprire grațioasă, repornire și restore din backup verificate pe copie.
- [ ] Testate primele activități RP; problemele și limitele comunicate.
- [ ] Instrucțiunile includ launcher, Java, RAM recomandat și depanare simplă.

### Gate C — înainte de deschiderea publică

- [ ] Proprietarul aprobă data, adresa publică și programul mentenanței.
- [ ] Staff-ul știe procedura pentru incidente, apeluri și raportări sensibile.
- [ ] Nu se promit TPS/FPS, capacitate sau uptime fără măsurători adecvate.
- [ ] Anunțul spune clar versiunea Minecraft, clientul Java compatibil, pluginurile server-side și schimbările majore.

## Administrarea schimbărilor

Fiecare propunere de mod/plugin/patch trebuie să noteze scopul de gameplay sau tehnic, dependențele, suprapunerile, compatibilitatea exactă, costurile măsurate ori „nemăsurat”, dovada, riscul și motivul includerii. Nu se elimină conținut RP și nu se schimbă reguli economice fără aprobarea proprietarului.
