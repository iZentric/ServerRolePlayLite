# 🏙️ ServerRolePlay **Lite**

Varianta **lite** a modpack-ului **Freeroam** (Palma City) — optimizată să meargă pe
**orice PC** (client) și pe **hosting gratuit** (server).

## 📦 Ce conține repo-ul

| Fișier / Folder | Ce face |
|---|---|
| `docs/HOSTING.md` | 🏆 Comparație hosting gratuit + recomandări pentru România |
| `docs/CLIENT-LITE.md` | Setări pentru PC-uri slabe (apare după analiza pack-ului) |
| `scripts/` | Scripturi de instalare server + generare pack lite |
| `server/` | Configurări optimizate de server (RAM mică, TPS stabil) |
| `analysis/` | Raportul analizei pack-ului original (ce s-a scos și de ce) |
