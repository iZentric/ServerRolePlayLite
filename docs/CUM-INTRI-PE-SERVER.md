# 🎮 CUM INTRI PE PALMA LITE RP — ghid pentru oricine, în 3 pași

> Merge pe ORICE PC — chiar și vechi, cu 4 GB RAM și fără placă video.

## Pasul 1 — Ia pack-ul (alege una din căi)
- **Calea ușoară:** descarcă [INSTALEAZA-PACK.bat](https://github.com/iZentric/ServerRolePlayLite/raw/arena/a29b4ef4-serverroleplaylite/deploy/INSTALEAZA-PACK.bat) → dublu-click → pack-ul apare pe Desktop
- **Calea manuală:** [Releases → lite](https://github.com/iZentric/ServerRolePlayLite/releases/tag/lite) → descarcă `Freeroam-Lite-Client-....mrpack`

## Pasul 2 — Instalează launcherul (o singură dată)
1. Descarcă **Prism Launcher**: https://prismlauncher.org/download
2. Deschide-l → **Add Instance → Import** → alege fișierul `.mrpack` de pe Desktop
3. (dacă îți cere Java: alege **Java 8 sau 11**)

## Pasul 3 — Intră în joc
1. Apasă **Launch**
2. Multiplayer → Add Server → pune adresa serverului (o primești de la șef)
3. Joacă! 🏙️ Orașul e în centru (protejat), survival liber în jur.
